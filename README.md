# AIML — Learning by Building

Hands-on ML at **1 hour a day**: build the core, break it, explain it.

## The loop (every day)

```
BUILD     Implement the core from scratch (small: the part interviewers probe)
BREAK IT  Write a prediction, run the experiment that should break it, explain the gap
EXPLAIN   Answer the drill questions out loud; one journal entry
```

## Current: [Machine Learning checklist](Machine%20Learning/CHECKLIST.md)

## Rules for AI use
1. Write the **core** from scratch yourself. AI is fine for plumbing (plots, data loading, env issues).
2. Stuck for more than 10 min? Ask for a hint and keep moving.
3. After you finish, ask Claude to review your code and quiz you.
4. Predict before you run anything in a break-it experiment.
